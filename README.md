# Homebrew tap for Vigilance

```sh
brew install vigihq/vigi/vigi
```

Then activate the free tier or install a Pro license:

```sh
vigi activate            # free, online, posts a signed report each run
# or Pro, offline and silent: https://vigihq.com/pro
```

Vigilance is commercial software from Modul4r Solutions. See <https://vigihq.com>.
